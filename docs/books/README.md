# Books and reference material

Source material the owner wants the agents' knowledge to draw on (owner 2026-11-12: "pelajari buku ini, dan
tentukan agent mana yang paling layak menggunakan knowledge ini").

## This repository is public

Every file committed here can be downloaded by anyone, and stays in the git history after it is deleted.

- Put here only material you have the right to publish: your own notes and summaries, open-licensed texts,
  or public-domain works.
- Do not commit a copy of a commercial or otherwise copyrighted book. Keep it in a private repository or
  share it in the session instead; what belongs here is the knowledge derived from it (a summary in your
  own words, the rules and thresholds, and the agent that uses them).

## Layout

- One folder per source: `docs/books/<short-name>/`.
- `NOTES.md` in it: the title, author and edition, what was taken from it, and which agent uses it.
- Knowledge that reaches an agent goes through the usual path (knowledge base, doctrine or prompt change
  by a reviewed PR); nothing in this folder is read by a Worker.
